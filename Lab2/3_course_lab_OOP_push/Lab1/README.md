# Лабораторна робота №1 — Транспорт

## Варіант
**Транспорт:** визначити ієрархію рухомого складу залізничного транспорту.

## Завдання
- створити пасажирський поїзд;
- порахувати загальну кількість пасажирів і багажу;
- відсортувати вагони за рівнем комфортності;
- знайти вагони за заданим діапазоном кількості пасажирів;
- використати класи, успадкування, поліморфізм та інкапсуляцію;
- покрити функціональність Unit-тестами JUnit 5 та Mockito.

## Ієрархія
```text
RollingStock
├── Locomotive
└── PassengerCarriage

PassengerTrain
└── List<PassengerCarriage>
```

`RollingStock` є базовим абстрактним класом. `Locomotive` і `PassengerCarriage` успадковують його спільні характеристики. `PassengerTrain` використовує композицію та містить список пасажирських вагонів.

Поліморфізм демонструється через перевизначення методу `getType()`.

## Основні операції
1. Підрахунок пасажирів.
2. Підрахунок багажу.
3. Сортування вагонів за комфортністю у спадному порядку.
4. Пошук вагонів за діапазоном місткості пасажирів.

## Технології
- Java 17
- Maven
- JUnit 5
- Mockito

## Запуск
```bash
mvn clean test
mvn compile
```

Програму можна запустити з IDE через клас `com.danil.transport.app.Main`.

## Тести
Проєкт містить JUnit 5 тести для моделей та бізнес-логіки, а також Mockito-тест для перевірки роботи `PassengerTrain` із залежностями.
